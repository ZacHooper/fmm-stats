# FM End of Season Review

Use this skill when the user asks for an end-of-season review, team review, or player awards for
their Football Manager save parsed via `fm-parser`.

## Context
- Analytics run against the DuckDB store generated by `fm-parser`, through the **`mart` schema**.
- The user reads these on Discord, so output must be punchy, narrative-driven text with bullet
  points, NOT massive markdown tables.
- The review has two parts: Tactical/Positional Review (for the coaches) and Player Awards
  (serious & silly).

## Behavioral Guardrails

**1. Query `mart`, never `staging`**
**[REQUEST]** "Run the end of season review for Frem."
**[BAD]** *Aggregates `staging.match_player_stats` directly and hand-rolls the phase dedup.*
**[GOOD]** *Reads `mart.player_seasons` / `mart.match_player_facts`, which have it applied.*
**[WHY]** `staging.*` holds one full row set per `(season, phase)` SNAPSHOT and
`match_player_stats` is a ring buffer that re-scrapes match history on every import. Summing
across phases double-counts; joining `staging.players` on a bare `tid` multiplies every stat row
by the number of snapshots the player appears in. `mart` applies all four rules once — see
`fmparser/mart.py`. If `mart` is missing the store predates it: rebuild with
`uv run python load_duckdb.py …` (which now builds it) rather than working around it.

**2. Appeared ≠ named in the squad**
**[REQUEST]** "Who had the best average rating?"
**[BAD]** *Averages `rating` over every row for the player.*
**[GOOD]** *Filters `appeared` (or uses `mart.player_seasons`, which already does).*
**[WHY]** An unused substitute still gets a row, carrying a **flat rating of 6.00** — 110 such
rows in Frem's 2024. Averaging them in drags every figure toward 6 and lets a pure benchwarmer
clear a "minimum games" filter. Mikkel Bruhn reads 6.66 unfiltered against 7.25 for the 20 games
he actually played.

**3. The Starter Filtering Rule (positional analysis only)**
**[GOOD]** *For UNIT breakdowns, filter `started AND subOn = 255` and require ~10 starts.*
**[WHY]** Sub appearances distort average ratings and defensive/passing volume. Positional
analysis evaluates pure starters. This is narrower than rule 2 — awards use `appeared`, units use
`started`.

**4. The DuckDB Lock Rule**
**[WHY]** A running Streamlit holds the write lock. Open read-only, or copy the store to the
scratchpad first. `scripts/_dbopen.open_readonly(path, tag=...)` does this properly.

**5. The Mobile Output Rule**
**[BAD]** *A 20-column markdown table of DataFrame output.*
**[GOOD]** *"🏆 **Golden Boot:** Adam Jakobsen (34 goals)"*
**[WHY]** Read on a phone via Discord. Wide tables break. Translate data into a tight narrative.

**6. Never surface raw CA/PA** — house rule. Reason with attributes, role ratings and
percentiles. Growth totals (`mart.player_growth*`) are attribute-derived and fine.

## Python Script Template

```python
import sys, duckdb, pandas as pd
sys.path.insert(0, "scripts")
from _dbopen import open_readonly

DB = "fm-frem.duckdb"          # or resolve via fmparser.careers
SEASON = None                  # None = latest season with matches

con, _ = open_readonly(DB, tag="season-review")

# Derived in the mart — no hardcoded tid. NOTE: use managed_club (the FIRST TEAM), not
# our_clubs, for anything match-related. our_clubs also holds the reserve side, whose 20
# fixtures would otherwise fold into the first team's 38 and corrupt every result and award.
# our_clubs is the right set for SQUAD membership, where a reserve player is still ours.
OURS = "(SELECT club_tid FROM mart.managed_club)"

if SEASON is None:
    SEASON = con.execute(
        f"SELECT MAX(season) FROM mart.match_player_facts WHERE team_tid IN {OURS}"
    ).fetchone()[0]
print(f"=== SEASON {SEASON} REVIEW ===")

# 1. RESULTS + FORMATIONS  (mart.matches is already deduped to one phase per season)
print("\n--- RESULTS BY COMPETITION ---")
print(con.execute(f"""
    SELECT competition, COUNT(*) AS games,
      SUM(CASE WHEN (home_tid IN {OURS} AND score_home > score_away)
                 OR (away_tid IN {OURS} AND score_away > score_home) THEN 1 ELSE 0 END) AS w,
      SUM(CASE WHEN score_home = score_away THEN 1 ELSE 0 END) AS d,
      SUM(CASE WHEN (home_tid IN {OURS} AND score_home < score_away)
                 OR (away_tid IN {OURS} AND score_away < score_home) THEN 1 ELSE 0 END) AS l,
      SUM(CASE WHEN home_tid IN {OURS} THEN score_home ELSE score_away END) AS gf,
      SUM(CASE WHEN home_tid IN {OURS} THEN score_away ELSE score_home END) AS ga
    FROM mart.matches
    WHERE season = {SEASON} AND (home_tid IN {OURS} OR away_tid IN {OURS})
    GROUP BY competition ORDER BY games DESC
""").df().to_string(index=False))

print("\n--- FORMATIONS ---")
print(con.execute(f"""
    SELECT formation, COUNT(*) AS games,
      SUM(CASE WHEN home_tid IN {OURS} THEN score_home ELSE score_away END) AS scored,
      SUM(CASE WHEN home_tid IN {OURS} THEN score_away ELSE score_home END) AS conceded
    FROM mart.matches
    WHERE season = {SEASON} AND (home_tid IN {OURS} OR away_tid IN {OURS})
    GROUP BY formation ORDER BY games DESC
""").df().to_string(index=False))

# 2. POSITIONAL UNITS — pure starters only (rule 3)
print("\n--- PLAYERS BY UNIT (10+ starts) ---")
print(con.execute(f"""
    WITH nm AS (SELECT DISTINCT person_id, name FROM mart.player_spells)
    SELECT CASE WHEN f.pos_order = 1 THEN 'GK'
                WHEN f.pos_order IN (2,3) THEN 'Fullbacks'
                WHEN f.pos_order IN (4,5) THEN 'Centerbacks'
                WHEN f.pos_order IN (6,7,8,9) THEN 'Midfielders / Wingers'
                WHEN f.pos_order IN (10,11) THEN 'Forwards' END AS unit,
           nm.name, COUNT(*) AS starts, ROUND(AVG(f.rating),2) AS avg_rating,
           SUM(f.goals) AS goals, SUM(f.assists) AS assists, SUM(f.keyPass) AS key_passes,
           SUM(f.tackW + f.intercept) AS def_actions, SUM(f.mistakes) AS mistakes
    FROM mart.match_player_facts f JOIN nm USING (person_id)
    WHERE f.season = {SEASON} AND f.team_tid IN {OURS} AND f.started
    GROUP BY unit, nm.name HAVING COUNT(*) >= 10
    ORDER BY CASE unit WHEN 'GK' THEN 1 WHEN 'Centerbacks' THEN 2 WHEN 'Fullbacks' THEN 3
                       WHEN 'Midfielders / Wingers' THEN 4 ELSE 5 END, avg_rating DESC
""").df().to_string(index=False))

# 3. AWARDS — appeared-only (rule 2). mart.player_seasons is per competition; roll it up.
df = con.execute(f"""
    WITH nm AS (SELECT DISTINCT person_id, name FROM mart.player_spells),
    tot AS (
      SELECT person_id, SUM(apps) AS games, SUM(minutes) AS minutes,
             ROUND(SUM(avg_rating * apps) / NULLIF(SUM(apps),0), 2) AS avg_rating,
             SUM(goals) AS goals, SUM(assists) AS assists, SUM(key_passes) AS key_passes,
             SUM(headW) AS headers_won, SUM(dribbles) AS dribbles, SUM(passC) AS passes_completed,
             SUM(shotA) AS shots, SUM(intercept + tackW) AS def_actions,
             SUM(mistakes) AS mistakes, SUM(yellows) AS yellows
      FROM mart.player_seasons
      WHERE season = {SEASON} AND team_tid IN {OURS} GROUP BY person_id)
    SELECT nm.name, g.age, t.*
    FROM tot t JOIN nm USING (person_id)
    LEFT JOIN mart.player_growth_season g USING (person_id)
    WHERE g.season = {SEASON} AND t.games > 3
""").df()

top = lambda c: df.nlargest(1, c)[["name", c]].to_dict("records")
print("\n--- AWARDS ---")
print("Player of Season:", top("avg_rating"))
u21 = df[df.age <= 21]
print("Young Player (U21):", u21.nlargest(1, "avg_rating")[["name","avg_rating"]].to_dict("records"))
for label, col in [("Golden Boot","goals"), ("Top Assister","assists"),
                   ("The Maestro (Key Passes)","key_passes"), ("Big Head (Headers)","headers_won"),
                   ("Quick Feet (Dribbles)","dribbles"), ("The Metronome (Passes)","passes_completed"),
                   ("The Brick Wall (Def Actions)","def_actions"), ("The Liability (Mistakes)","mistakes"),
                   ("The Butcher (Yellows)","yellows")]:
    print(f"{label}:", top(col))

# 4. MOST IMPROVED — attribute growth, real reads only, real squad only.
#    growth_comparable drops the estimate->exact artifact a new signing produces;
#    squad_on() drops loan-ins whose loan has actually expired.
print("\n--- MOST IMPROVED (season) ---")
print(con.execute(f"""
    SELECT g.name, g.age, g.start_total, g.end_total, g.growth, g.minutes
    FROM mart.player_growth_season g
    WHERE g.season = {SEASON} AND g.growth_comparable
      AND EXISTS (SELECT 1 FROM mart.squad_on(DATE '{SEASON}-03-01') s
                  WHERE s.person_id = g.person_id)
    ORDER BY g.growth DESC LIMIT 5
""").df().to_string(index=False))

# Long-run context — a season understates a long server (Garly: +11 in 2024, +36 since joining).
print("\n--- GROWTH SINCE JOINING (top 5) ---")
print(con.execute(f"""
    SELECT t.name, t.age_on_arrival, t.age_now, t.growth,
           ROUND(t.days_at_club/365.0,1) AS yrs, t.growth_per_365
    FROM mart.player_growth_tenure t
    WHERE t.growth_comparable
      AND EXISTS (SELECT 1 FROM mart.squad_on(DATE '{SEASON}-03-01') s
                  WHERE s.person_id = t.person_id)
    ORDER BY t.growth DESC LIMIT 5
""").df().to_string(index=False))

# 5. THE STORMTROOPER — most shots, no goal, one match. Note the phase filter comes free.
print("\nThe Stormtrooper:", con.execute(f"""
    WITH nm AS (SELECT DISTINCT person_id, name FROM mart.player_spells)
    SELECT nm.name, f.shotA, f.date FROM mart.match_player_facts f JOIN nm USING (person_id)
    WHERE f.season = {SEASON} AND f.team_tid IN {OURS} AND f.goals = 0 AND f.appeared
    ORDER BY f.shotA DESC LIMIT 1
""").df().to_dict("records"))
```

## Review Execution Steps
1. Resolve the store for the career (`fm-<key>.duckdb`); confirm `mart` exists in it.
2. Run the script (read-only open handles the Streamlit lock).
3. Sanity-check one number against a known figure before writing prose.
4. Turn the output into an engaging, Discord-friendly summary.

## Reporting notes
- **Goals-for and player-attributed goals differ** and both are right: an opposition own goal
  counts to the team score without being attributed to any of our players. Frem 2024 = 73 team
  goals, 70 player goals, 3 own goals. Say which one you mean.
- **League standings frequently do not parse** — do not assert a final league position from the
  store. Ask the user, or report record and goal difference only.
