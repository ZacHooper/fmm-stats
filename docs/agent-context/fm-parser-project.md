**Key structural facts found:**
- Strings are length-prefixed with a 4-byte little-endian length.
- Entity records: `TID(XXXX0000) | UID(4 bytes) | len | name...` — e.g. Bucaspor 1928 club TID=`a7 19` (6567) at offset 10099086.
- IDs stored little-endian (Google gives big-endian; reverse).

**SOLVED — per-match player stats (FMM22):** located at ~56.5MB. Match-stat blocks are **54 bytes**, separated by an **8-byte 0xFF delimiter** (stride 62). One team's XI is contiguous by lineup order; `posOrder` byte [41] = lineup slot (Demir GK=1). Block-start invariant: condition[3] in 1..100, 5-byte FF run at [13:18], posOrder[41] 1..30, TID[42:46] nonzero. The old mojo field map is CORRECT for FMM22 — all 17 comparable fields validated 100% for all 11 starters. **SOLVED — match header + season extractor (`season_extract.py`):** Match-stats region ~56.2MB (56195250) to 56587455 = **75 match anchors** ~5150B apart. Header contains event list (goals/cards: minute+playerTID) and `[homeTID:u16][awayTID:u16][day:u16][year:u16==0x07xx][attendance:u16]`. Date = Jan1 + day (day119/2022 = 2022-04-30). **Event format (refined):** unit = `[b0][b1=TYPE][min:u16][b4][playerTID:u32][ff ff]`. b1 type: 01=goal, 02=own_goal, 03=penalty, 06=injury (all confirmed vs screenshots); 04=missed_penalty, 05=red_card, 29=disallowed_goal(offside) — ALL confirmed vs in-game. Plain yellow cards are NOT in this stream. b0=modifier (goals: how-scored/assist). b0 varies within a type (not the discriminator). Own goals aren't in any player's `goals` field, so SCORE = sum(player goals per team) + own-goals credited to the OPPOSING team. Event TIDs validated against the match's 40 players (fixes earlier miss of TIDs <20000). Stoppage-time minute encoding is quirky (u16 high byte = added mins) — cosmetic.
